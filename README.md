# Signalist 📈

Signalist is a stock market tracking web application built with **Next.js and TypeScript**.

The project is currently under development.

## 🚀 Project Goals

* Track stock market information
* Display stock prices and market data
* Create and manage watchlists
* Set stock price alerts
* Provide AI-powered market insights
* Build a clean and responsive user interface

## 🛠️ Tech Stack

* Next.js
* TypeScript
* MongoDB
* Better Auth
* Inngest

## 📌 Status

🚧 **In Development**

This project is actively being developed and new features will be added over time.

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/Darshang45/Signalist.git
```

Navigate to the project:

```bash
cd Signalist
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
